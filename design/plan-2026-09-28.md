# mesa-clm implementation plan (v1.1, 2026-09-28)

## 1. Context

mesa-anyjev (v0.1.0, `6159281`) already proposes calibrated, ontology-grounded AVUs with full provenance, but through AnyJev's logprob readout (top-20 logprob cap, noul twins for K>8, missing-label abstains, one slow prompt per candidate). Contrastive LM (CLM `bb42c6c5`) scores candidate texts against a state with a frozen Qwen3-8B last-token encoder + 512-d heads + scaled-cosine softmax: no option limit, cacheable candidate vectors — but its released head is weak zero-shot on typed questions (Score state-independent #3; suffix collapse 0.958 vs 0.452 state-only #15; inverted calibration #15; logreg on frozen embeddings beats the fine-tuned head, PR #13). A read-only check also found that a **no-model lookup baseline already scores LOCO acc 0.772 (term.fits) / 0.800 (column.ontology_fits)** by copying the label of the same (scope, column, CURIE) from other cards — beating AnyJev L2's 0.765 on term.fits. mesa-clm is therefore a standalone, torch-free MESA annotator that ports mesa-anyjev's generic layers, asks CLM *rank-first* questions with a fixed abstain anchor, fingerprints everything embedding-dependent, earns trust only through pre-registered, leakage-aware, nested-selection LOCO cells, ships proposed-only first, and then plugs into neon-ducklake's curate→validate seam without changing that contract. 0.1.0 annotate runs where the serving stack is reachable (sparky-1); DE-VM reach is M8.

### At a glance

- **What ships first (0.1.0):** `mesa-clm` CLI + mesa-mcp plugin (`mesa_clm_annotate|apply|explain|feedback|health`), proposed-only, annotate → review (MRTR / CLI) → apply to iRODS + MESA history (spool by default, direct CLI-only), with `revert`.
- **Model path:** vLLM pooling container (Qwen3-8B bf16) :8090 + patched `clm-serve` (CPU heads) :8700 on sparky-1 loopback with keys; mesa-clm core is a torch-free httpx client with vendored `clm/schema.py`.
- **Decision model:** one `/v1/systemone` Choice per candidate group (`{CURIE: "label: definition", "__none__": anchor}`), state-only contexts that end with the target; tiers `zero_shot → calibrated (Platt/T) → probe (local numpy on 4096/512-d features) → head (fine-tuned, M7)`.
- **Evidence gates:** M2 runs the pre-registered framing A/B (X1) and baselines (X2) before any tier is trusted; every `auto` threshold must cite a nested LOCO cell that beats the lookup baseline on novel keys; kill/pivot criteria K0–K4 are fixed up front.
- **Order:** M0 scaffold/ports/labels → M1 serving + hermetic pipeline (two tracks) → M2 evidence → M3 live proposed-only loop → M4 learned tiers → M5 release 0.1.0 → M6 neon adapter (0.2.0) → M7 head tier → M8 scale-out / evidence-gated auto.
- **Needs your explicit go-ahead during execution:** creating `idss-mesa/mesa-clm` on GitHub; the CARC GPU-allocation request; upstream PRs (mesa-ducklake lock/spool, mesa-mcp plugin allowlist + per-write client, neon-ducklake curator switch, docs/install.sh); the live `~/.mesa/.venv` bump; the live Data Store smoke test.

## 4. Decision model

**4.1 Shapes**
- `rank_fit`: `/v1/systemone` Choice, `criteria={<curie|id>: candidate_text, "__none__": anchor_text}`, `instructions=framing.instructions` (None unless A1 picks F4). `p_fit = σ(s_c)` at zero_shot, `σ(a·s_c+b)` once calibrated. Winner = argmax s_c; anchor wins → `abstain(anchor_won)`.
- `choice`: closed options, no anchor; `confidence = max(probs)`.
- Requests always use temperature 1; calibration is client-side. CLM's softmax is float64 `math.exp`, unrounded (`schema.py:115-119`), scale clamped at 100 → min p ≈ e^-200 > 0; no underflow re-query: `assert p > 0`, violation → `numeric_underflow` + abstain.
- Questions sharing a context go in one request.
- Tier routing: zero_shot/calibrated → clm-serve `model=clm-latest|clm-raw`; probe → `EncoderClient.embed` → `headproj` → `LinearHead` locally (bypasses clm-serve); head → clm-serve `model=<served head>`.

**4.7 Policy and citation**
- `outcome(rec, t, profile)`:
  0. `method='rule'` → rule outcome; `method='ols_rank'` → `proposed` if `rank ≤ t.ols_rank_top` (default 1) else `abstain`; never auto.
  1. **abstain** if probs None, `answer_index<0`, `truncated`, anchor won, or all masked.
  2. **auto** only if `t.auto` set ∧ `LEVEL_RANK[level] ≥ max(t.min_level, profile.min_level_write)` ∧ `calibration ∈ profile.auto_calibrations` ∧ `stat ≥ t.auto` (stat = `p_fit` for rank_fit, `confidence` for choice) ∧ `margin ≥ t.margin` ∧ the cite is valid and fingerprint-matched.
  3. **proposed** if `stat ≥ t.propose`; 4. else **abstain**. The group margin can only demote an auto (no cite needed).
- Profiles: `prod {min_level_write: calibrated, auto_calibrations:[platt, temperature], auto_requires_audit: true, allow_history_none: false}`; `dev {min_level_write: zero_shot, allow_auto_write: false, allow_history_none: true}`. Shipped with every `auto: null`.
- `tests/test_policy_citations.py`, per numeric `auto`: `cite` matches `^bench/results/\d{4}-\d{2}-\d{2}/[\w.\-]+\.json#<task>\.<tier>\.<framing>$`; the cell has `loco, pre_registered, selection:"nested", exploratory:false, n_folds≥5, teacher_in_test:false, servable`, `masked` equal to serving, `labels_sha256` equal to a committed snapshot; guards `n_neg≥30` (rank_fit) or `n_nonmodal≥30` (choice); fingerprint and `question_key` equal the live ones; `fold_choices` agree with A1 in ≥5/7 folds; `beats_lookup_novel == true`; `auto ≥ cell.threshold_cp[t.risk]` (smallest t whose pooled held-out {stat ≥ t} has ≥30 items and a one-sided 95% Clopper-Pearson error upper bound ≤ risk).
- With `auto_requires_audit`, apply also needs a passing `audits` row: ≥50 would-be-auto decisions from ≥3 non-bench cards, curator-reviewed, CP-95 error upper bound ≤ 2×risk.

**5.4 LOCO, metrics, rule R, leakage controls**
- Folds: `for card in sorted(fold_eligible_cards)`; guards 30 train / 5 held-out per class (all 14 term/ontology folds pass at 0.5, verified) + floors 100 (calibrated) / 40 (probe/head).
- Teacher rows: train drops teacher rows whose `leak_group` equals the held-out product; property test: no `fold_eligible=false`, same-product teacher or `bench_card` curator row reaches a test fold. Predictions pooled, never fold-averaged.
- Nested selection (D27): every choice among framings/models/anchors/specs/hyperparameters is re-made inside each outer fold by grouped inner CV on the 6 training cards; cells record `fold_choices`.
- Cell fields — identity: `question_key, fingerprint, labels_sha256, feature_spec, label_sources, teacher, teacher_in_test:false, masked, loco, selection, pre_registered, exploratory, servable, n_folds, skipped_folds, fold_choices`; counts: `n, n_neg, n_nonmodal, class_counts`; metrics: `acc, macro_f1, brier, nll, ece, cov@5%, cov@10%, aurc, auroc[cluster CI], threshold_cp{0.05,0.10}`; baselines: `majority_acc, lookup_acc, lookup_nll, novel_key{n, acc, auroc, nll}, lopo{acc, nll}, beats_lookup_novel`; diagnostics: `mean_state_cos, calls, input_tokens, ms_per_decision`.
- **Rule R** ("A ≻ B on m") needs both: (i) the one-sided 95% lower bound of a card-cluster paired bootstrap of Δm (resample held-out cards, B=2000, seed 0) > 0; (ii) A beats B on ≥⌈0.8·m_c⌉ of the m_c held-out cards with ≥10 evaluable items (m_c<4 → `insufficient_clusters`). "A ≽ B within δ" = cluster LB > −δ. Effect floors (AUROC ≥0.60, ECE ≤0.08) are always paired with a CI condition. `bench mde` simulates the minimum detectable effect at the realised n, base rates and 7 cards; committed to DESIGN.md with X1–X4.
- **Lookup as a probability model:** `lookup_prob` = Laplace-smoothed (α=1) key frequency over training cards, falling back to the training prior for unseen keys (so on novel keys AUROC 0.5, NLL = prior cross-entropy). **`beats_lookup_novel` := novel-key AUROC cluster-LB > 0.5 ∧ novel-key NLL ≻ `lookup_prob` (rule R).** Novel-key accuracy vs majority (0.717 term.fits, 0.667 ontology_fits; verified) is reported, not gated.
- Verified controls (read-only): lookup LOCO 0.772/0.800; leave-one-product-out 0.723/0.721; novel-key subsets term.fits 159 (45 Yes/114 No), ontology_fits 99 (33/66).
